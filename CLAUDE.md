# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Language

Everything committed to this repository must be in English: code, comments, commit messages, branch names, MR titles/descriptions, issues, and Wiki pages. Conversation with the user may be in Portuguese, but nothing written to the repo or GitLab should be.

## Issue tracking

Before starting work, check open issues (`glab issue list`) for one that matches. Reference the issue number in the MR description (e.g. `Closes #12`) so it closes automatically on merge. If work doesn't match an existing issue, ask whether to create one before proceeding, rather than doing untracked work.
